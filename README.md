## ⚡ The Four Architectural Pillars

### 1. Home & Biography (`index.html`)
- **Celestial Backdrop & Starfield**: Subtle hardware-accelerated canvas background, dimmed for optimal typography contrast (`opacity: 0.62`, `brightness: 0.85`).
- **Interactive GSAP Hover Cards**: Glassmorphic cards in the About/Biography section that gently expand (`scale: 1.025`) and amplify ambient gold drop-shadows on cursor hover.
- **Cinematic Mandatory Scroll-Snap**: Fixed lateral navigation dots with intersection observers for fluid page jump points.
- **Multidisciplinary FAQ & JSON-LD**: Interactive accordion with comprehensive Schema.org `FAQPage` structured data for search engine rich results.
- **Lead Capture Form**: Asynchronous inquiry submission pipeline with instant validation and feedback toasts.

### 2. Web Architecture & Engineering (`web-services.html`)
- **Dual Counter-Flow Infinite Carousels**:
  - Top track streams systems toward the right; bottom track streams systems toward the left.
  - Hovering pauses track movement; clicking opens full system specifications in an inspection modal.
- **7-Project Paginated Repeater Grid**:
  - Displays systems in strictly paginated blocks of 7 with dynamic item numbering, previous/next controls, and page status badges.
- **Comprehensive Project Inspection Modal**:
  - Dynamically displays system categories, technology tags, architectural descriptions, authentic GitHub repository links, and active live site URLs.
- **Web Architecture FAQ & JSON-LD**: Answers common technical questions on uptime, edge CDN caching, code handoffs, and testing standards.
- **Intro Video Stream**: Embedded executive introduction video (`https://www.youtube.com/watch?v=JSl9UcDaywA`).

### 3. Creative AI Space (`creative-space.html`)
- **Virtual Director Deck & Latent Viewfinder HUD**:
  - **Live Timecode**: Real-time 24fps REC timecode counter (`00:04:12:18`).
  - **Optical Camera Lens Switcher**: Instantly toggles between 35mm Anamorphic, 24mm Macro Probe, 35mm UGC Prime, and IMAX 70mm Grand-Format setups.
  - **Dynamic Aspect Ratio Control**: Live viewport resizing between 2.39:1 CinemaScope, 16:9 Standard 4K, and 9:16 Vertical UGC Social.
  - **Optical Crosshairs & Corner HUD Brackets**: Broadcast viewfinder reticle overlay with cinematic chiaroscuro vignettes.
  - **Audio Waveform Visualizer**: Live HTML5 canvas animating ambient audio frequencies in real time.
  - **4 Interactive Production Presets**: Clickable scene presets (Cinema Trailer, Luxury Commercial, Viral UGC Ad, Architectural Flythrough) with instantaneous flash transitions and prompt updates.
- **Pinned Card Stack Unfolding Feature**:
  - Previous video works are visibly stacked upon arrival.
  - As visitors scroll down, the cards smoothly unfold and elevate one after the other via GSAP ScrollTrigger scrubbing.
  - Scrolling upward reverses the sequence back into a neat stack.
  - Includes chevron navigation buttons and active card counter.
- **Creative AI FAQ & JSON-LD**: Covers prompt engineering, commercial broadcast ownership, DaVinci Resolve color grading, and neural models.
- **Intro Video Stream**: Embedded creative introduction reel (`https://youtu.be/sECemgPYcFg`).

### 4. Leadership, Business & Holistic Vitality (`leadership-business.html`)
- **Accelerated Bio-Cellular Living Canvas**:
  - High-velocity biological simulation representing mitochondrial energy, cellular respiration, and immune sentinels.
  - Virus pathogens spawn periodically, targeted and dissolved into golden nutrient particles by rapid Y-shaped antibody sentinels.
  - Running ~2.5x faster to instantly communicate cellular defense and vitality.
- **5-Pillar Distributor Duplication Blueprint**:
  - Complete structural model for distributor onboarding, team coaching, rank advancement, and wholesale health distribution.
- **Leadership & Health FAQ & JSON-LD**: Details executive mentorship formats, duplication playbooks, and cellular health ordering.

## 🛸 Interactive Global Features

- **Adaptive Scroll-Aware Navigation Bar**:
  - Always fully visible in the hero and top sections.
  - Smoothly translates out of view (`nav-hidden`) when scrolling downward.
  - Briefly reappears with a timer upon detecting an upward scroll.
- **Global Floating Contact Bar**:
  - Fixed left-edge quick contact drawer with direct access to Email, WhatsApp, Calendar, and Inquiry forms.
- **WCAG 2.1 AA Accessibility Modal**:
  - In-browser accessibility customization:
    - High-contrast mode toggle.
    - +10% typography scale override.
    - Reduced motion switch (suspends canvas loops and GSAP animations).
- **Sequential Footer Navigation Bar**:
  - Standardized `< ^ >` navigation across all pages with automated page boundary awareness (e.g. Page 1 disables previous, Page 4 disables next).
- **Bespoke Gold SVG Favicon (`favicon.svg`)**:
  - Scalable vector icon featuring the architectural gold monogram and celestial halo.

## 🛠️ Technology Stack & Dependencies

- **Core Scripting**: TypeScript / Vanilla ES6+ (Zero unnecessary framework overhead)
- **Styling & Design System**: Tailwind CSS (with custom obsidian `#0D0F12`, surface `#12161A`, and gold `#E6C280` / `#FFF3CD` palette)
- **Animation Engine**: GSAP 3.12 + ScrollTrigger (Scrubbed timelines, pinned sections, scale & shadow physics)
- **Visuals & Graphics**: Custom HTML5 Canvas 2D render loops (Starfields, cellular simulations, audio wave analyzers)
- **Icons**: FontAwesome 6 Pro CDN
- **Typography**: Plus Jakarta Sans, Outfit, Inter, and JetBrains Mono (Google Fonts)
- **Structured Data**: JSON-LD (`FAQPage`, `Person`, `Organization`, `WebSite`)
- **Backend API**: Node.js Express server (`server.js`) with REST lead ingestion endpoint (`/api/leads`)

## 🚀 Local Development & Execution

### Prerequisites
- Node.js (v18+) or Bun (v1.0+)
- npm or bun package manager

### Installation
```bash
# Clone the repository
git clone https://github.com/reel3dlab/hodm-portfolio.git

# Navigate into project directory
cd hodm-portfolio

# Install dependencies
npm install
```

### Running Locally
```bash
# Start development / production server
npm start
# Server listens on http://localhost:3000
```

### Building & Verification
```bash
# Run build check
npm run build

# Run linting check
npm run lint
```
